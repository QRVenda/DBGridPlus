# DBGridPlus

Componente DBGrid para formatação de colunas e linhas.  
Formata colunas para valores e datas, permite agrupamento e totalização no rodapé, autodimensiona as colunas e permite definir largura mínima.

---

## ⚙️ Configuração

Adicione os caminhos do componente no **Library Path** do Delphi.

### Caminhos a adicionar:
DBGridPlus\package  
DBGridPlus\src

### Como configurar no Delphi:
Tools → Options → Language → Delphi → Library → Library Path
